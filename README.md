## Запуск проектов

Для каждого проекта:

1. Перейдите в соответствующую ветку
2. Создайте виртуальное окружение: `python -m venv ve`
3. Активируйте окружение: `source ve/bin/activate` (Linux/Mac) или `ve\Scripts\activate` (Windows)
4. Установите зависимости: `pip install -r requirements.txt`
5. Запустите приложение: `flask run`
